# Machine Learning workspace

This workspace will contain the Vietnamese NLP pipeline, dataset preparation, feature extraction, model training and evaluation.

- `data/raw/`: source datasets (kept out of Git).
- `data/interim/`: intermediate transformed data (kept out of Git).
- `data/processed/`: training-ready datasets (kept out of Git).
- `src/preprocessing/`: text cleaning and normalization.
- `src/features/`: feature extraction.
- `src/models/`: classical and deep-learning model code.
- `src/evaluation/`: metrics and error analysis.
- `artifacts/`: trained model artifacts (kept out of Git).
- `notebooks/`: experiments.
- `reports/`: generated experiment reports (kept out of Git).

No training code or model is included in Phase 1.
